# ADR 0002：鍵盤重新顯示時重載工具列設定

## 狀態

已採用。

## 背景

鍵盤 extension 在容器 app 變更自訂工具列後可能仍留在記憶體中。只在
`viewDidLoad` 建立工具列，會使既有 extension 行程繼續顯示舊設定。

## 決策

每次 `viewWillAppear` 重新讀取皮膚與 App Group 偏好、重建 CandidateBar 工具列，
並套回目前中英模式。工具列可見時，鍵面將頂端 6pt 留白讓給 CandidateBar，
使下緣觸控仍可交給工具列圖示。

## 後果

工具列配置在鍵盤下次出現時可靠生效，且右側收折圖示等工具列按鈕的下緣觸控不會
被第一排鍵攔截。
